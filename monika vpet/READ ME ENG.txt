MONIKA VPET DESKTOP — MAS AUTOSTART (BETA)

INSTALLATION
1. Close MAS.
2. Copy the entire “monika vpet” folder to: Doki Doki Literature Club/game/Submods/
If the Submods folder does not exist, create it. Keep the folder name as is; do not copy just the .rpy file.
3. Install 64-bit Python 3 from python.org if not already installed. During installation, enable “Add Python to PATH”.
4. Open CMD in the “game/Submods/monika vpet” folder and run:
python -m pip install PySide6 google-genai
5. Open monika_config.json with Notepad, paste your Gemini API key into the gemini_api_key value, and save the file. 
Example: {"gemini_api_key": "PASTE_YOUR_API_KEY_HERE"}
6. Open MAS. The pet will launch automatically and display a random greeting; double-click the chibi to show/hide the chat box; drag the chibi to move it; right-click to open the menu.
7. System-wide shortcut: Ctrl+Alt+M to hide/show Monika. In the right-click menu, select “Hide Monika” to hide her temporarily; “Exit Monika” terminates the program, and the shortcut will not work until MAS launches the pet again.

CHIBI IMAGES
Place transparent PNG images in the same folder as monika_desktop.py and name them:
- monika.png (normal)
- happy.png (happy)
- thinking.png (thinking)
If no images are found, the program will display a Monika icon instead.

NOTES
- Python and the required libraries must be installed on your machine. - If automatic startup fails, set the `MONIKA_PYTHONW` environment variable to point to the full path of `pythonw.exe` (e.g., `C:\Users\NAME\AppData\Local\Programs\Python\Python312\pythonw.exe`).
- If the API key was ever hardcoded or shared via chat, revoke it in Google AI Studio and generate a new one. Store the new key only on your local machine.
- The launcher now passes the MAS PID to the desktop pet and monitors the process; if MAS closes or crashes, the pet will automatically exit. Ren'Py's quit callback remains as a fallback.

DEBUGGING AUTO-START ISSUES
Check `game/monika_vpet_autostart.log` and `game/monika_vpet_desktop.log` after launching MAS. These logs, generated by the updated launcher, indicate whether MAS successfully located the script/Python and reveal why the desktop process failed.

Launcher update: If the current MAS/Ren'Py build rejects the child environment, the launcher will now attempt to start the desktop process without an explicit environment mapping.
